### Network Engineering Labs Portfolio

В данном репозитории собраны практические работы по сетевым технологиям: от базовых настроек до протоколов маршрутизации и автоматизации. Целью создания репозитория является — отработка навыков, необходимых для CCNA и реальных задач сетевого инженера.
  
---
This repository contains practical lab exercises on networking technologies: from basic configurations to routing protocols and automation. The purpose of the repository is to develop the skills required for the CCNA certification and real‑world tasks of a network engineer.

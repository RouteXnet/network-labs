**Цель лабораторной работы:**
Цель этого лабораторного упражнения — научиться и понять, как настраивать статические записи MAC‑адресов для защиты портов (port security). По умолчанию MAC‑записи на порту коммутатора изучаются динамически. Статические записи MAC‑адресов настраиваются администратором вручную.

**Задание 1:**
Настройте имена хостов для коммутатора SW1 и маршрутизатора R1 в соответствии с приведённой топологией. Создайте VLAN 4010 на коммутаторе SW1 и назначьте порт FastEthernet0/1 в этот VLAN в качестве порта доступа (access port).

**Задание 2:**
Настройте IP‑адрес 172.16.0.1/27 на интерфейсе FastEthernet0/1 маршрутизатора R1 и IP‑адрес 172.16.0.2/27 на интерфейсе VLAN 4010 коммутатора SW1. Проверьте, что R1 может выполнить ping до SW1, и наоборот.

**Задание 3:**
Настройте защиту порта (port security) на порту FastEthernet0/1 коммутатора SW1 для следующих статических MAC‑адресов:

- 000a.1111.ab01;
- 000b.2222.cd01;
- 000c.3333.ef01;
- 000d.4444.ac01.

Коммутатор должен ограничивать доступ для MAC‑адресов, которые не указаны в списке. Проверьте конфигурацию с помощью команд port security в Cisco IOS.
